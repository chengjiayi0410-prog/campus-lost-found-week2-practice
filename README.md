# 校园失物招领

一个面向校园的失物与招领信息平台。用户可以搜索物品、按类型和分类筛选、查看详情、注册登录、发布信息，管理员可以删除违规内容。

当前进度：**第 3 周 Express、MySQL 与 JWT 认证 API**。

## 已实现功能

- 首页失物招领列表
- 关键词搜索
- 失物、招领类型筛选
- 物品分类筛选
- 多条件组合筛选
- 信息详情页
- 用户模拟注册和登录
- 登录状态路由保护
- 发布信息与必填校验
- 图片本地预览
- 管理员信息列表和删除操作
- 手机端响应式布局

## 技术栈

- Vue 3
- Vite
- Vue Router
- 原生 CSS
- 本地假数据

## 页面

| 地址 | 页面 | 说明 |
| --- | --- | --- |
| `/` | 首页 | 搜索、筛选和列表 |
| `/items/:id` | 详情 | 查看单条信息 |
| `/login` | 登录 | 模拟登录 |
| `/register` | 注册 | 模拟注册 |
| `/publish` | 发布 | 需要登录 |
| `/admin` | 管理后台 | 需要管理员权限 |
